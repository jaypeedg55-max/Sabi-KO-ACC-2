# Sabi Ko v1.9 test build

Extract repository contents into the root of your GitHub repository, keeping the `app/` and `.github/` folder structures. In GitHub Actions run **Build Sabi Ko v1.9 Test APK**. Download **Sabi-Ko-v1.9-test-APK** and extract `app-debug.apk`.

This is the v1.9 adaptive preview embedded as Android WebView HTML with native TTS fallback, not a verified compiled APK. Google Filipino voice availability depends on the device. The application ID stays `ph.sabiko.app`; updating an older installed APK can fail if signed with a different GitHub debug key. Do not uninstall your previous app if it has personal data until you have a verified backup. Existing web page browser storage and APK storage are separate. No guarantee of safe automatic migration of custom content.
