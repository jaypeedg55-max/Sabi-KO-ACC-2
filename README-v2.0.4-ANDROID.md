# Sabi Ko v2.0.4 Android test build

Includes the corrected v2.0.4 HTML UI preview in app/src/main/assets/index.html,
the native Android WebView and voice bridge, plus a GitHub Actions debug APK workflow.

Upload the *contents* of this ZIP to the root of Sabi-KO-ACC-2 (main).
Run Actions > Build Sabi Ko v2.0.4 Test APK > Run workflow.
Download the Sabi-Ko-v2.0.4-test-APK artifact, extract and install app-debug.apk.

This source ZIP is not itself an APK. Compilation and real-device interaction have not been verified.
Keep backups of any personalized buttons/recordings before replacing an older install.
